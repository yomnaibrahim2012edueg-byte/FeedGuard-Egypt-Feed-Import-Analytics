## 📌 Project Overview

FeedGuard is a data analytics project focused on analyzing Egypt's feed import market and understanding the key factors affecting import costs, pricing trends, and supply chain risks.

The project provides interactive Power BI dashboards to explore import volumes, import values, exchange-rate movements, economic crises, and global supplier sourcing patterns.

## 🎯 Project Objectives

- Analyze Egypt's feed import trends from 2015 to 2025.
- Understand the relationship between exchange rates and import costs.
- Evaluate the impact of global and local crises on feed imports.
- Analyze supplier countries and sourcing concentration.
- Identify key market risks and pricing trends.

## 📊 Dashboard Pages

1. **Executive Overview:** A general overview of Egypt's feed import market.
2. **Volume & Value:** Analysis of import quantities, values, and pricing trends.
3. **Crisis & Financial Impact:** Evaluating the impact of economic and geopolitical crises.
4. **Currency Dynamics:** Analyzing exchange-rate movements and their relationship with import costs.
5. **Sourcing Risk:** Exploring supplier countries and import dependency.
